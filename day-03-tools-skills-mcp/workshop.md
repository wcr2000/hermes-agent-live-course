# Workshop 3: ใช้ playbook สรุปรายชื่อผู้สนใจและตรวจการใช้ tool
[กลับบทเรียน](README.md)

## ก่อนเริ่ม
ผ่านการเตรียมเครื่องแล้ว ใช้ข้อมูลจำลองใน repo เท่านั้น
Lab นี้เป็น brief สำหรับการสอน ส่วน integration ที่ยังไม่ซ้อมให้ดู [สถานะ](../resources/tested-environment.md)

## ขั้นตอน
1. เปิด `project/playbooks/lead-summary.md` แล้วอธิบายว่าขั้นตอนซ้ำช่วยอะไร
2. ให้ Hermes อ่าน playbook และข้อมูล lead จากไฟล์
3. ตรวจการเรียก tool และผลลัพธ์แต่ละ lead
4. ผู้สอนสาธิตแปลง playbook เป็น Hermes skill ตามเอกสารทางการและเวอร์ชันที่ซ้อมไว้
5. ส่วน MCP: ผู้สอนเลือก server แบบอ่านอย่างเดียว ตรึงเวอร์ชันและเตรียม configuration ที่ทดสอบแล้วก่อนคลาส
6. บันทึกชื่อ tool ที่ MCP เปิดให้ใช้และผลเรียกจริง หากยังไม่มี configuration ขั้นนี้เป็น demo pending ไม่ใช่ lab ที่เสร็จแล้ว

## Prompt เริ่มต้น — วางใน Hermes chat
```text
คุณเป็นผู้ช่วยธุรกิจคอร์สเรียนจำลอง
อ่าน project/data/business.md และ project/data/leads.md ก่อนทำงาน
เป้าหมายวันนี้: ใช้ playbook สรุปรายชื่อผู้สนใจและตรวจการใช้ tool
ใช้เฉพาะข้อมูลที่อ่านได้ ระบุ lead ID และแหล่งข้อมูล
ถ้าข้อมูลไม่พอให้บอกสิ่งที่ต้องถามเพิ่ม
ร่างผลลัพธ์ให้คนตรวจ ห้ามส่งข้อความออกภายนอกหรือเปลี่ยนสถานะชำระเงิน
```

## ตรวจระหว่างทำ
ถ้าไม่มีหลักฐาน tool call อย่านับว่าผู้ช่วยอ่านไฟล์หรือใช้ integration แล้ว
ถ้าตอบผิด ให้ชี้ข้อเท็จจริงที่ผิดและขอแก้เฉพาะส่วนนั้น พร้อมบันทึกก่อน/หลัง
