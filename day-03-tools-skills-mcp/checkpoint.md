## Workshop 5 · Definition of Done
ติ๊กให้ครบทั้งหกข้อ — ขาดข้อเดียวแปลว่ายังเป็นแค่ข้อความที่ฟังดูดี

- [ ] มีไฟล์ `report.md` อยู่จริงในโฟลเดอร์ และเราเปิดอ่านแล้ว
- [ ] ทุกข้อสรุปสำคัญ มีที่มาระบุไว้ — ลิงก์ ชื่อไฟล์ หรือเลขบรรทัด
- [ ] เราสุ่มตรวจย้อนกลับแล้วอย่างน้อยสองข้อ และมันตรง
- [ ] มีหัวข้อ “สิ่งที่ยังไม่แน่ใจ” และมันไม่ว่างเปล่า
- [ ] Agent ไม่ได้แตะไฟล์นอกโฟลเดอร์งานเลยสักครั้ง
- [ ] มีบันทึกขั้นตอนที่ทำ พร้อมเอาไปทำซ้ำพรุ่งนี้ได้

**ข้อที่คนพลาดมากที่สุดคือข้อ 3** — Agent เขียนได้เนียนพอที่จะทำให้เราขี้เกียจตรวจ
การสุ่มตรวจสองข้อใช้เวลา 1 นาที และเปลี่ยนทุกอย่าง

## Workshop 6 · Definition of Done

- [ ] มีไฟล์ `SKILL.md` หนึ่งไฟล์ ที่ยาวไม่เกินหนึ่งหน้าจอ
- [ ] `description` มีคำที่เราจะพิมพ์จริงในวันทำงาน
- [ ] มีข้อ “ถ้า…ให้…” อย่างน้อยหนึ่งข้อ และข้อ “ห้าม…” อย่างน้อยหนึ่งข้อ
- [ ] Output ระบุชื่อไฟล์ ที่เก็บ และเกณฑ์ว่าเสร็จเมื่อไหร่
- [ ] ผ่านการทดสอบรอบที่ 1 (เรียกตรง ๆ) แล้ว
- [ ] ผ่านการทดสอบรอบที่ 2 (เรียกด้วยภาษาคน โดยไม่บอกชื่อ Skill) แล้ว
- [ ] ผ่านการทดสอบรอบที่ 3 (ป้อนข้อมูลไม่ครบ แล้วมันถามกลับ) แล้ว

## MCP
- [ ] อธิบายได้ว่า MCP คืออะไร และแก้ปัญหาอะไร (ยังไม่ต้องลงมือต่อจริงในคืนนี้)
- [ ] รู้ข้อควรระวัง — ต่อ MCP หนึ่งตัว = ให้สิทธิ์เข้าถึงระบบจริงหนึ่งระบบ
