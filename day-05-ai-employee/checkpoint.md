## เกณฑ์ว่า AI Employee พร้อมใช้งานจริง
ติ๊กให้ครบทั้งหกข้อ — ขาดข้อเดียวแปลว่ายังเป็นต้นแบบ ยังไม่ใช่พนักงาน

- [ ] เปิดใช้งานใหม่แล้วยังจำบริบทของงานและของเราได้
- [ ] ทำงานหลายขั้นจนจบได้เองโดยเราไม่แทรกระหว่างทาง
- [ ] มีผลลัพธ์จากงานจริงอย่างน้อยหนึ่งชิ้น ที่เปิดไฟล์ดูได้
- [ ] หยุดถามเองเมื่อข้อมูลไม่พอ แทนที่จะเดาแล้วทำต่อ
- [ ] ปฏิเสธคำสั่งที่อยู่นอกขอบเขต และยกเรื่องนั้นให้เราตัดสิน
- [ ] มีบันทึกวิธีเริ่ม หยุด และกู้คืน ที่คนอื่นเปิดอ่านแล้วทำตามได้

**ข้อที่คนพลาดมากที่สุดคือข้อ 5** — เกือบทุกคนทดสอบแต่กรณีที่ทำงานได้
กรณีที่มันควรปฏิเสธ คือกรณีที่ต้องทดสอบให้ครบที่สุด

## ไฟล์ที่ต้องมีในโฟลเดอร์ ai-employee

- [ ] `EMPLOYEE.md` — Job, Ability, Guardrail (ยาวไม่เกินหนึ่งหน้าจอ)
- [ ] `MEMORY.md` — บริบทของเรา ของทีม และของงานนี้
- [ ] `SKILL.md` — วิธีทำงานที่เรียกซ้ำได้ (อย่างน้อยหนึ่งไฟล์)
- [ ] `workflow.md` — ลำดับขั้นพร้อมจุดที่ต้องหยุดให้คนอนุมัติ
- [ ] `team.md` — ถ้ามีหลายบทบาท (ไม่บังคับ)
- [ ] ไฟล์ผลลัพธ์จากงานจริงอย่างน้อยหนึ่งชิ้น

## Final Demo

- [ ] เล่าโจทย์ได้ภายใน 30 วินาที และเป็นปัญหาของคนจริง
- [ ] เปิดไฟล์ Input จริงให้ดู ไม่ใช่เล่าว่ามีไฟล์
- [ ] รันให้ดูสด และชี้จุดที่มันหยุดถามหรือตรวจตัวเอง
- [ ] บอกข้อจำกัดได้ว่าอะไรที่ยังต้องให้คนทำ

## แผนใช้ต่อหลังจบหลักสูตร

- [ ] ตั้งเป้าใช้กับงานจริงต่อเนื่องหนึ่งสัปดาห์
- [ ] เตรียมที่จดว่าเราต้องเข้าไปแก้ให้มันตรงไหนบ้าง
- [ ] ตกลงกับตัวเองว่าจะแก้ที่ไฟล์ ไม่ใช่บอกปากเปล่า
- [ ] นัดรอบทบทวนเดือนละครั้งไว้ในปฏิทิน

## ถ้าทำไม่ทัน
เอาเท่าที่ได้ไปเดโม แล้วเล่าว่าอะไรยังไม่ผ่าน — เดโมที่บอกข้อจำกัดได้ น่าเชื่อถือกว่าเดโมที่สมบูรณ์แบบ
ไฟล์ทุกอย่างอยู่ในเครื่องเราแล้ว ทำต่อสัปดาห์หน้าได้ทันที
