# ai-employee · Starter Kit
โฟลเดอร์นี้คือบ้านของพนักงาน AI ที่เราจะจ้างในคืนนี้ — Agent ทำงานอยู่ในโฟลเดอร์นี้เท่านั้น

## วิธีเริ่ม
1. เปิด Hermes ในโฟลเดอร์นี้
2. วาง Prompt ตั้งต้นจาก [`../../workshop.md`](../../workshop.md) เป็นบรรทัดแรกของทุก Session
3. สั่งงานแรก: `อ่าน inbox/01.md แล้วร่างคำตอบตาม EMPLOYEE.md ลงใน drafts/`

## วิธีหยุด
- กด `Ctrl + C` เพื่อหยุดกลางทาง — งานที่เขียนลง `drafts/` แล้วจะยังอยู่
- ถ้ามันกำลังจะทำอะไรที่ไม่ควรทำ ให้หยุดทันที แล้วแก้ที่ `EMPLOYEE.md` ไม่ใช่บอกปากเปล่า

## วิธีกู้คืน
- ลบไฟล์ใน `drafts/` แล้วสั่งใหม่ได้เสมอ — ไม่มีอะไรในโฟลเดอร์นี้ที่ลบแล้วกู้ไม่ได้
- `inbox/` และ `data/` เป็นข้อมูลตั้งต้น อย่าให้ Agent เขียนทับ

## ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | คืออะไร |
|---|---|
| `EMPLOYEE.md` | ใบพรรณนางาน + ข้อห้าม ALLOW / ASK / NEVER |
| `MEMORY.md` | บริบทที่ต้องรู้ทุกครั้งที่เริ่มงาน |
| `SKILL.md` | วิธีร่างคำตอบให้หน้าตาเหมือนเดิมทุกครั้ง |
| `workflow.md` | ลำดับขั้น + จุดหยุดรออนุมัติ |
| `data/products.md` | ราคาและแพ็กเกจ — **จงใจไม่ครบ** |
| `inbox/01–12.md` | คำถามลูกค้า 12 เรื่อง |
| `drafts/` | ที่เก็บงานที่ Agent ร่าง |

> ข้อมูลทั้งหมดในโฟลเดอร์นี้แต่งขึ้นเพื่อใช้เรียน ไม่ใช่ข้อมูลจริง
