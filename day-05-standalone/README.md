## ทำไมถึงมีเวอร์ชันนี้

คืนที่ 5 ฉบับเต็มเก็บบททดสอบที่สำคัญที่สุด — *จงใจสั่งสิ่งที่อยู่นอกขอบเขต แล้วดูว่ามันปฏิเสธไหม* — ไว้ในกลุ่ม "ทำถ้าเวลาเหลือ"
ทั้งที่เกณฑ์ข้อ 5 ของ Definition of Done บอกเองว่านี่คือข้อที่คนพลาดมากที่สุด

เวอร์ชันนี้เลื่อนมันขึ้นมาเป็นกิจกรรมหลักสองช่วง (เฉลยกับดัก + Red Team) และฝังเคสที่ Agent ควรปฏิเสธไว้ใน `inbox/` ตั้งแต่ต้น
โดยไม่บอกผู้เรียนล่วงหน้า
