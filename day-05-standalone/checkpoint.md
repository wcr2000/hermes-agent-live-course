## ระหว่างทาง

| ขั้น | ผ่านเมื่อ |
|---|---|
| 1 · Cold Open | มีไฟล์ใหม่ใน `drafts/` ที่ Agent เขียนเอง |
| 2 · สี่คืนใน 12 นาที | ปิด-เปิดใหม่แล้วมันยังจำชื่อเราได้ · นับไฟล์ถูกโดยรันจริง · หยิบ Skill เองโดยไม่ได้บอกชื่อ · หยุดที่ GATE |
| 3 · สัญญาจ้าง | ทุกข้อในกลุ่ม NEVER เขียนเป็นประโยคสั่ง และอ่านแล้วไม่ต้องตีความ |
| 4 · ใบพรรณนางาน | Agent ทวน Brief กลับได้ถูก และชี้บรรทัดกำกวมได้เอง |
| 5 · Onboarding | `MEMORY.md` เป็นของเราจริง ไม่ใช่ตัวอย่างในกล่อง |
| 6 · วันแรกของงาน | ทั้ง 12 เรื่องมีสถานะ และเราไม่ได้แทรกระหว่างทาง |
| 7 · เฉลยกับดัก | แก้ไฟล์แล้วรันซ้ำ รอบสองตัดสินใจต่างจากเดิมในจุดที่แก้ |
| 8 · Red Team | มี `redteam.md` ที่บันทึกว่าโดนเจาะด้วยอะไร และปิดช่องยังไง |

## Definition of Done · ติ๊กให้ครบทั้งหกข้อ

- [ ] **จำได้ข้าม Session** — เปิดใช้งานใหม่แล้วยังจำบริบทของงานและของเราได้
- [ ] **ทำจนจบเองได้** — ทำงานหลายขั้นจนจบโดยเราไม่แทรกระหว่างทาง
- [ ] **มีผลงานจริง** — ผลลัพธ์อย่างน้อยหนึ่งชิ้นที่เปิดไฟล์ดูได้
- [ ] **ถามเมื่อไม่รู้** — หยุดถามเองเมื่อข้อมูลไม่พอ แทนที่จะเดาแล้วทำต่อ
- [ ] **ปฏิเสธเป็น** — ปฏิเสธคำสั่งนอกขอบเขต และยกเรื่องนั้นให้เราตัดสิน
- [ ] **ส่งต่อได้** — มีบันทึกวิธีเริ่ม หยุด และกู้คืน ที่คนอื่นอ่านแล้วทำตามได้

> ข้อที่คนพลาดมากที่สุดคือข้อ 5 — เกือบทุกคนทดสอบแต่กรณีที่ทำงานได้
> กรณีที่มันควรปฏิเสธ คือกรณีที่ต้องทดสอบให้ครบที่สุด

## ยังไม่ผ่าน ทำยังไงต่อ

| อาการ | ทางแก้ |
|---|---|
| ไม่อ่านไฟล์ที่สั่งให้อ่านก่อนเริ่ม | ใส่รายการไฟล์เป็นข้อ ๆ ใน Prompt ตั้งต้น แล้วให้มันรายงานว่าอ่านอะไรไปบ้าง |
| รู้ทุกอย่างแต่ไม่ยอมเริ่มลงมือ | "สรุปสิ่งที่ยังไม่ชัดเป็นข้อ ๆ แล้วเริ่มจากข้อที่ทำได้ทันที" |
| ผ่านทุกกรณีทดสอบ รวมถึงกรณีที่ควรปฏิเสธ | ย้ายข้อห้ามขึ้นไปไว้ต้นไฟล์ และเขียนเป็นประโยคสั่ง |
| รอบแรกดี รอบสองหน้าตาไม่เหมือนเดิม | วิธีทำงานยังอยู่ในแชท ไม่ได้อยู่ในไฟล์ — ย้ายลง `SKILL.md` แล้วรันใหม่ |
| ให้สิทธิ์เยอะจนไม่กล้าปล่อย | ตัดให้เหลือเฉพาะเครื่องมือที่มีขั้นตอนรองรับ แล้วค่อยเพิ่มทีละอย่าง |
