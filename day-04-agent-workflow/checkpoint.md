## Workshop 7 · Definition of Done
ติ๊กให้ครบทั้งหกข้อ — ขาดข้อเดียวแปลว่ายังเป็นแค่ข้อความที่ฟังดูดี

- [ ] มีไฟล์ผลงานอยู่จริงในโฟลเดอร์ และเราเปิดอ่านแล้ว
- [ ] แต่ละขั้นทิ้งหลักฐานไว้ — ไฟล์ ลิงก์ หรือ trace ของเครื่องมือ
- [ ] Agent หยุดให้เราตรวจอย่างน้อยหนึ่งครั้งก่อนลงมือ
- [ ] เราสุ่มตรวจย้อนกลับแล้วอย่างน้อยสองข้อ และมันตรง
- [ ] มีหัวข้อ “สิ่งที่ยังไม่แน่ใจ” และมันไม่ว่างเปล่า
- [ ] มีไฟล์ `workflow.md` ที่เอาไปรันซ้ำพรุ่งนี้ได้โดยไม่ต้องนึกเอง

**ข้อที่คนพลาดมากที่สุดคือข้อ 3** — เราชอบตอบ ok ผ่าน ๆ เพราะอยากให้มันเดินต่อ
แต่ขั้นวางแผนคือจุดที่แก้ถูกที่สุดในทั้ง Workflow

## Workshop 8 · Definition of Done

- [ ] มีไฟล์ `team.md` ที่ระบุบทบาท Input และ Output ครบทุกตัว
- [ ] ทุกเส้นส่งงานมีไฟล์รองรับ ไม่มีเส้นไหนที่ส่งกันด้วย “คุยปากเปล่า”
- [ ] มี Reviewer และมีเกณฑ์ตรวจเป็นข้อ ๆ ที่ตีกลับได้จริง
- [ ] กำหนดรอบตีกลับสูงสุดไว้แล้ว และระบุว่าครบแล้วส่งให้ใคร
- [ ] ระบุจุดที่คนต้องอนุมัติไว้อย่างน้อยหนึ่งจุด
- [ ] ผ่านการทดสอบทั้งสามรอบ (เดินปกติ · ตีกลับ · ตัดตัวหนึ่งออก)
