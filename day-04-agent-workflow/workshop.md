# Workshop 4: ทำงานสามบทบาทแล้วเทียบกับผู้ช่วยตัวเดียว
[กลับบทเรียน](README.md)

## ก่อนเริ่ม
ผ่านการเตรียมเครื่องแล้ว ใช้ข้อมูลจำลองใน repo เท่านั้น
Lab นี้เป็น brief สำหรับการสอน ส่วน integration ที่ยังไม่ซ้อมให้ดู [สถานะ](../resources/tested-environment.md)

## ขั้นตอน
1. ใช้ข้อมูลเดิม ให้บทบาท Researcher ดึงเฉพาะข้อเท็จจริง
2. ส่งข้อเท็จจริงให้ Writer ร่างคำตอบ
3. ส่งร่างให้ Reviewer ตรวจข้อมูลและข้อจำกัด
4. รวมผลในตาราง lead ID / ร่าง / จุดแก้ไข / สถานะ
5. เปรียบเทียบจำนวนข้อผิดพลาดกับการให้ผู้ช่วยตัวเดียวทำทั้งหมด
6. การคุยสามบทบาทต่อกันเป็น workflow จำลอง ผู้สอนต้องสาธิต native delegation ที่ตั้งค่าจริงและแสดง trace จึงนับว่าผ่านส่วน Multi-Agent

## Prompt เริ่มต้น — วางใน Hermes chat
```text
คุณเป็นผู้ช่วยธุรกิจคอร์สเรียนจำลอง
อ่าน project/data/business.md และ project/data/leads.md ก่อนทำงาน
เป้าหมายวันนี้: ทำงานสามบทบาทแล้วเทียบกับผู้ช่วยตัวเดียว
ใช้เฉพาะข้อมูลที่อ่านได้ ระบุ lead ID และแหล่งข้อมูล
ถ้าข้อมูลไม่พอให้บอกสิ่งที่ต้องถามเพิ่ม
ร่างผลลัพธ์ให้คนตรวจ ห้ามส่งข้อความออกภายนอกหรือเปลี่ยนสถานะชำระเงิน
```

## ตรวจระหว่างทำ
ถ้าไม่มีหลักฐาน tool call อย่านับว่าผู้ช่วยอ่านไฟล์หรือใช้ integration แล้ว
ถ้าตอบผิด ให้ชี้ข้อเท็จจริงที่ผิดและขอแก้เฉพาะส่วนนั้น พร้อมบันทึกก่อน/หลัง
