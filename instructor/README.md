# คู่มือจัด repo และใช้สอน
## เหตุผลการออกแบบ
ให้ผู้เรียนเลือกวันก่อน แล้วอ่าน README เป็นทางเข้าของวันนั้น ลดการค้นข้าม Notes/Code/Prompts หลายตำแหน่ง
ใช้ข้อมูลกลางและโปรเจกต์เดียวเพื่อเห็นพัฒนาการ

## ก่อนคลาส
1. ตรวจ outline ฉบับเต็มและแก้แผนรายวัน
2. เลือก Hermes version และ model แล้วเติมบันทึกทดสอบ
3. เติม integration จริงเฉพาะที่จะสอน ซ้อมจากเครื่องสะอาดตามทุกขั้น
4. ใส่ภาพผลลัพธ์ที่ปกปิดข้อมูลลับไว้ข้างขั้นตอน
5. เมื่อพร้อม สร้าง release ของเอกสารสำหรับรุ่นเรียน เช่น cohort-2026-09-v1
6. สร้าง tag checkpoint หลังซ้อมแต่ละวัน เพื่อให้ย้อนกลับได้ โดยยังไม่สร้าง tag ล่วงหน้าในชุดนี้

## ระหว่างคลาส
เปิด README → บอกผลลัพธ์ → อธิบายภาพ → สาธิต → ให้ทำตาม → หยุดตรวจ checkpoint
ให้ผู้เรียนอ่านผ่าน browser ได้ Git clone/fork เป็นทางเลือก

## หลังคลาส
แก้ข้อผิดพลาดใน Markdown แล้วจดใน CHANGELOG ไม่เปลี่ยนชุดคำสั่งกลางคลาสโดยไม่ประกาศ
เก็บเฉลยเป็นข้อความและไฟล์ที่ดู diff ได้ ใช้ ZIP สำหรับดาวน์โหลด release

## Repository บน GitHub
[hermes-agent-live-course](https://github.com/wcr2000/hermes-agent-live-course) เป็น Public เพื่อให้ผู้เรียนเปิดอ่านตามคลาสได้
แก้บทเรียนใน branch แล้วตรวจ diff และลิงก์ก่อนรวมเข้า main
ยังไม่ได้กำหนด LICENSE สำหรับการนำเนื้อหาไปเผยแพร่ต่อ
