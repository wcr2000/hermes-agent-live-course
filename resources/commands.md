# คำสั่งและ Prompt ที่ใช้บ่อย
[กลับหน้าแรก](../README.md)

## Terminal

| คำสั่ง | หน้าที่ | ใช้คืนไหน |
|---|---|---|
| `hermes setup` | ตั้งค่าผ่านตัวช่วย | 1 |
| `hermes model` | เลือก provider / model | 1 |
| `hermes` | เปิด CLI (Session ใหม่) | ทุกคืน |
| `hermes --continue` | เปิด Session ล่าสุดต่อ | 2 |
| `hermes --version` | ตรวจเวอร์ชันที่ติดตั้ง | 1 |

> คำสั่ง MCP, การติดตั้ง Skill และ delegation จะเพิ่มในนี้หลังตรึงเวอร์ชันและซ้อมจริง
> ดู [สถานะการทดสอบ](tested-environment.md) · ตรวจกับ [Quickstart ทางการ](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart/) ควบคู่เสมอ

## Prompt ที่ใช้ซ้ำได้ทุกคืน

**จำกัดขอบเขต** — วางเป็นบรรทัดแรกเสมอ
```text
ทำงานอยู่ในโฟลเดอร์ ________ เท่านั้น
ถ้าจะลบหรือเขียนทับไฟล์เดิม ให้ถามผมก่อนเสมอ
```

**บังคับให้ไปดูของจริง**
```text
ก่อนสรุป ให้ list โฟลเดอร์และอ่านไฟล์จริงก่อน แล้วบอกว่าอ่านอะไรไปบ้าง
```

**ขอแผนก่อนลงมือ**
```text
สรุปโจทย์เป็นแผนย่อยให้ผมอ่านก่อน แล้วรอผมตอบ ok
```

**ตรวจงานย้อนกลับ**
```text
สุ่มตรวจข้ออ้าง 2 ข้อย้อนกลับไปหาแหล่ง แล้วรายงานว่าข้อไหนตรง ข้อไหนยังไม่แน่ใจ
```

**กู้สถานการณ์เมื่อ Context บวม**
```text
สรุปสถานะตอนนี้ 5 บรรทัด
```
แล้วเปิด Session ใหม่ด้วยสรุปนั้น + ชื่อไฟล์ที่มีอยู่

**เปลี่ยนงานที่เพิ่งทำให้เป็น Skill**
```text
สรุปขั้นตอนที่เพิ่งทำเป็นรายการสั้น ๆ ให้หน่อย
```
