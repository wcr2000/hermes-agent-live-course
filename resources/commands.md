# คำสั่งอ้างอิงเบื้องต้น
ตรวจเอกสารทางการวันที่ 2026-09-06 แต่ยังไม่ได้รันทดสอบในสภาพแวดล้อมคลาส

| รันใน Terminal | หน้าที่ |
|---|---|
| `hermes setup` | ตั้งค่าผ่านตัวช่วย |
| `hermes model` | เลือก provider/model |
| `hermes` | เปิด CLI |
| `hermes --continue` | เปิด session ล่าสุดต่อ |
