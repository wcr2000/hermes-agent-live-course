## ข้อที่คนพลาดมากที่สุดคือข้อ 6
Memory ที่เขียนว่า “ชอบงานเป็นระเบียบ” ฟังดูดีแต่ตรวจไม่ได้ — เขียนใหม่ให้เป็นสิ่งที่ชี้ได้ว่าทำตามหรือยัง

## ถ้าทำไม่ทัน
เขียน User Memory ให้จบก่อนสามบรรทัดก็พอ แล้วค่อยเติม Project Memory ทีหลัง
Memory ที่สั้นแต่จริง ใช้งานได้ดีกว่า Memory ที่ยาวแต่ยังไม่ได้ทดสอบ

## การบ้าน
ใช้ Agent กับงานจริงสองงานในสัปดาห์นี้ แล้วทุกครั้งที่ต้องอธิบายบริบทซ้ำ ให้จดไว้
บันทึกนั้นคือบรรทัดที่ยังขาดใน `MEMORY.md`
