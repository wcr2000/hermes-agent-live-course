## วันนี้คุณจะทำอะไรได้
ผู้ช่วยทำงานต่อเนื่องและแยกข้อมูลถาวรออกจากบริบทชั่วคราว

## แนวคิดที่ใช้
Session, Context, Persistent memory

## ลำดับเรียนที่เสนอ (120 นาที)
| เวลา | กิจกรรม |
|---|---|
| 0–15 นาที | ทบทวนและอธิบายแนวคิดด้วยภาพ |
| 15–35 นาที | ผู้สอนสาธิตงานปลายทาง |
| 35–75 นาที | ผู้เรียนทำ Workshop ตามขั้นตอน |
| 75–85 นาที | พัก |
| 85–110 นาที | ทดลองกรณีผิดพลาดและปรับงาน |
| 110–120 นาที | ตรวจ checkpoint และถามตอบ |

ตารางนี้เป็นข้อเสนอจัดคลาส ไม่ใช่เวลาที่คัดจาก outline ต้นฉบับ

## เริ่มลงมือ
เปิด [Workshop](workshop.md) แล้วทำทีละข้อ ข้อมูลทั้งหมดมาจาก [โปรเจกต์กลาง](../project/README.md)

แสดงหลักฐานว่าข้อมูลใดจำได้ พร้อมระบุวิธีทดสอบ

เปลี่ยนธุรกิจจำลองเป็นธุรกิจที่สนใจ โดยใช้ข้อมูลแต่งขึ้นและเกณฑ์ตรวจเดิม
