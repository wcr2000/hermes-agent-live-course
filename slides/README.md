# แผนสไลด์แนวคิด
ยังไม่มีไฟล์ PowerPoint/PDF ในชุดนี้

| วัน | ภาพหลักที่ควรทำ |
|---|---|
| 1 | ผู้ใช้มอบหมายงาน / Model เลือกการทำงาน / Tool ส่งผลกลับ |
| 2 | กระดานงานชั่วคราว เทียบสมุดข้อมูลที่ใช้ต่อเนื่อง |
| 3 | Tool = การกระทำ, Skill = วิธีทำงาน, MCP = การเชื่อมเครื่องมือ |
| 4 | ผู้ค้นข้อมูล ผู้เขียน ผู้ตรวจ พร้อมทางส่งงานกลับแก้ |
| 5 | หน้าที่พนักงานและจุดอนุมัติของคน |

ใส่แนวคิด ตัวอย่าง และข้อจำกัดลงสไลด์ ส่วน command/config/prompt ยาวให้อยู่ในบทเรียน GitHub
ภาพควรช่วยให้เข้าใจ ไม่ลดทอนจนทำให้เข้าใจผิด เช่น การมี memory ไม่ได้แปลว่าจำทุกอย่างถูกต้อง
