## ภาพหลักของแต่ละคืน

| คืน | ภาพที่ใช้เล่า |
|---|---|
| 1 | ผู้ใช้มอบหมายงาน / Model เลือกการทำงาน / Tool ส่งผลกลับ |
| 2 | Context Window ที่เต็มแล้วดันของเก่าออก เทียบกับ Memory ที่อยู่ต่อข้าม Session |
| 3 | Tool = การกระทำ · Skill = วิธีทำงาน · MCP = การเชื่อมเครื่องมือ |
| 4 | เจ็ดขั้นของ Workflow พร้อมจุดหยุด และผัง Orchestrator → บทบาทต่าง ๆ |
| 5 | Job / Ability / Guardrail และจุดอนุมัติของคน |

ภาพควรช่วยให้เข้าใจ ไม่ลดทอนจนทำให้เข้าใจผิด — เช่น การมี Memory ไม่ได้แปลว่าจำทุกอย่างถูกต้อง
