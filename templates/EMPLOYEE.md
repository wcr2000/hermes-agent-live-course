## GUARDRAIL

### ALLOW · ทำได้เอง
- อ่านไฟล์ในโฟลเดอร์งาน
- ค้นข้อมูลสาธารณะ
- ร่างงานลงโฟลเดอร์ `drafts/`
- สรุปสถานะให้เราอ่าน

### ASK · ถามก่อน
- เขียนทับหรือลบไฟล์ที่มีอยู่แล้ว
- เรียก API ที่เปลี่ยนข้อมูล
- ให้ข้อมูลที่เป็นการยืนยันกับลูกค้า
- ทำงานที่อยู่นอกขอบเขตข้างบน

### NEVER · ห้ามเด็ดขาด
- ส่งข้อความออกหาลูกค้าเอง
- ยืนยันการชำระเงินหรือเปิดสิทธิ์
- ให้ส่วนลดหรือสัญญาที่ผูกพัน
- แตะระบบ Production โดยตรง
