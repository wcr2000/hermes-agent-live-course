# Day N — ชื่อบทเรียน
> เทมเพลตสำหรับผู้สอน · โครงนี้ตรงกับที่ Day 1–5 ใช้จริง

## เป้าหมายของคืนนี้
หนึ่งประโยค + ตาราง 3–4 ข้อว่าจบแล้วผู้เรียนทำอะไรได้

## กำหนดการ
ตารางเวลา · ช่วง · นาที (ให้ตรงกับสไลด์หน้า “กำหนดการ”)

## ก่อนเริ่ม · เตรียมให้พร้อมใน 3 นาที
4 ข้อ: เปิดอะไร สร้างโฟลเดอร์อะไร เอาไฟล์ของคืนก่อนมาจากไหน เตรียมโจทย์อะไรมาในใจ

## Session N · หัวข้อ (เวลา)
แนวคิดหลัก + ตารางเปรียบเทียบ + ตัวอย่างที่เดินตามทีละขั้น

## Workshop N · ชื่อ (เวลา)
- เลือกหนึ่งเส้น (A / B / C)
- Prompt ตั้งต้นแบบคัดลอกไปวางได้เลย + ตารางอธิบายว่าแต่ละบรรทัดมีไว้ทำไม
- เดินทีละขั้น: สิ่งที่เราพิมพ์ → ต้องเห็น → ถ้าไม่ตรงทำอย่างไร
- ตารางสิ่งที่ต้องได้ (Deliverables)
- ติดตรงนี้ · ทำแบบนี้ (Troubleshoot 4 ข้อ)
- เสร็จก่อนเวลา · ลองต่ออีกสามข้อ

## Checkpoint
เกณฑ์สังเกตได้ + ระบุข้อที่คนพลาดมากที่สุด + “ถ้าทำไม่ทัน”

## การบ้านก่อนคืนถัดไป
3–4 ข้อ ที่ใช้เวลารวมไม่เกิน 40 นาที และผลลัพธ์เป็นไฟล์

## ต่อไป
ลิงก์บทถัดไป
