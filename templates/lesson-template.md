# Day N — ชื่อบทเรียน
## ผลลัพธ์
ระบุชิ้นงานที่ผู้เรียนจะได้
## ก่อนเริ่ม
ระบุไฟล์และความพร้อมที่ต้องมี
## แนวคิด
คำอธิบายสั้นและภาพหนึ่งเรื่อง
## ขั้นตอน
แต่ละขั้นต้องมี: ทำที่ไหน → ทำอะไร → command/prompt → ผลที่คาดหวัง → ถ้าผิดให้ตรวจอะไร
แยก code block ของ Terminal กับ prompt สำหรับ AI
## Checkpoint

## Troubleshooting
