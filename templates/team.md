# team.md — เทมเพลต
> ใช้ในคืนที่ 4 · Workshop 8 · [กลับบทเรียน](../day-04-agent-workflow/workshop.md)

```
Orchestrator → Researcher → Analyst → Writer → Reviewer → คุณ (อนุมัติ)
                                                    └── ตีกลับได้ไม่เกิน 2 รอบ
```

เริ่มจากสามตัวก่อนก็พอ — Researcher, Writer, Reviewer ครอบคลุมงานส่วนใหญ่แล้ว

## ORCHESTRATOR
- โจทย์ใหญ่: ________
- แตกเป็น ____ บทบาท
- ตีกลับได้ไม่เกิน 2 รอบ ครบแล้วส่งให้ ________ ตัดสิน
- เครื่องมือ: อ่านไฟล์ + มอบหมายงาน เท่านั้น (กันไม่ให้ลงไปทำเอง)

## RESEARCHER
- รับ: โจทย์ + ขอบเขต
- ใช้: ________
- ส่ง: `research.md` + แหล่งที่มาทุกข้อ
- ห้าม: ตีความหรือสรุปแทน Analyst

## ANALYST *(ใส่เมื่อจำเป็น)*
- รับ: `research.md`
- ส่ง: `analysis.md` — ข้อสรุป เหตุผล และสิ่งที่ตัดทิ้งพร้อมเหตุผล
- ห้าม: ใช้ข้อมูลที่ไม่มีใน `research.md`

## WRITER
- รับ: `research.md` (และ `analysis.md` ถ้ามี)
- ใช้: Skill ________
- ส่ง: `draft.md` ตามรูปแบบ ________
- ห้าม: เพิ่มข้อมูลที่ไม่มีในไฟล์

## REVIEWER
- รับ: `draft.md` + ข้อมูลต้นทาง
- เกณฑ์ตรวจ:
  1. ________
  2. ________
  3. ________
- ส่ง: `review.md` ระบุข้อที่ต้องแก้ และข้อที่ **บล็อกการส่ง**
- ต้องรายงานข้อที่ไม่ผ่านอย่างน้อยหนึ่งข้อ

## คุณ (มนุษย์)
- รับ: `draft.md` + `review.md`
- ตัดสินใจ: อนุมัติ / ให้แก้ / ยกเลิก

---

## ทดสอบสามรอบ

| รอบ | ทำอะไร | ผ่านเมื่อ |
|---|---|---|
| 1 · เดินตามเส้นปกติ | สวมบทบาททีละตัว ส่งไฟล์ต่อกันจริง | ทุกตัวได้ไฟล์ครบโดยไม่ต้องถามเพิ่ม |
| 2 · ให้ Reviewer ตีกลับ | จงใจส่งร่างที่ขาดที่มาหนึ่งข้อ | ตีกลับถูกตัว พร้อมบอกว่าต้องแก้อะไร |
| 3 · ตัดตัวหนึ่งออก | ลองเอา Analyst ออก | งานยังเดินได้ = เริ่มด้วยทีมเล็กกว่านี้ก็พอ |
