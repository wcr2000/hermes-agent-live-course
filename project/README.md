# ชุดข้อมูลสำรอง — AI Course Assistant
[กลับหน้าแรก](../README.md)

Workshop ทุกคืนออกแบบให้ใช้ **งานจริงของตัวเอง** — ส่วนนี้มีไว้สำหรับคนที่ยังหยิบงานจริงมาลองไม่ได้
เช่น ข้อมูลเป็นความลับ หรือยังนึกโจทย์ไม่ออกในคาบ

ชื่อ ราคา และข้อความทั้งหมดในชุดนี้ **แต่งขึ้นเพื่อใช้เรียน** ไม่ใช่ข้อมูลจริงของหลักสูตรนี้

## ไฟล์ในชุดนี้
1. [ข้อมูลธุรกิจ](data/business.md)
2. [ข้อความผู้สนใจ](data/leads.md)

4. [ตัวอย่างผลลัพธ์](example-output.md)
5. [กรณีทดสอบ](evaluation.md)

## ใช้ยังไงในแต่ละคืน

| คืน | ใช้แทนงานจริงอย่างไร |
|---|---|
| 1 | ให้ Agent อ่าน `business.md` แล้วสรุปข้อเท็จจริง 3 ข้อและสิ่งที่ยังไม่รู้ |
| 2 | ใช้ธุรกิจนี้เป็น Project Memory — คำศัพท์ ราคา และข้อห้าม |
| 3 | เอา `lead-summary.md` มาเขียนเป็น `SKILL.md` |
| 4 | แตกงานตอบลูกค้าเป็น Workflow แล้วแบ่งบทบาท Researcher / Writer / Reviewer |
| 5 | ประกอบเป็น AI Employee แล้ววัดผลด้วย [กรณีทดสอบ](evaluation.md) ทั้ง 5 ข้อ |

> ถ้ามีงานจริงของตัวเอง ให้ใช้งานจริงเสมอ — ชุดนี้เป็นทางสำรอง ไม่ใช่เส้นทางหลัก
