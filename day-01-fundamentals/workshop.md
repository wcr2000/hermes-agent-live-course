## Workshop 1 · Build Your First Hermes Agent
**20:50 – 21:35 น. · 45 นาที · ทำพร้อมกันทั้งห้อง**

จบ Workshop นี้ทุกคนจะมี Agent ที่รันได้จริงบนเครื่องตัวเอง

### เจ็ดขั้นตอนที่จะทำร่วมกัน

| # | ขั้นตอน | ผลที่ต้องเห็น |
|---|---|---|
| 01 | ติดตั้ง Hermes | พิมพ์ `hermes --version` แล้วขึ้นเลขเวอร์ชัน |
| 02 | ตั้งค่า Environment | `hermes setup` จบโดยไม่มี error |
| 03 | เชื่อมต่อ Model Provider | `hermes model` แล้วเลือก provider/model ได้ |
| 04 | สร้าง Workspace | มีโฟลเดอร์ `my-work/day1-workshop` และเปิด Hermes อยู่ในนั้น |
| 05 | ทดลองสั่ง Agent ทำงาน | ตอบกลับได้ และเราเห็นว่ามันเรียกเครื่องมืออะไร |
| 06 | ให้ Agent อ่านและสร้างไฟล์ | มีไฟล์ใหม่เกิดขึ้นจริงในโฟลเดอร์ |
| 07 | ทดลอง Task ที่มีหลายขั้นตอน | งานเดียวที่ต้องอ่าน คิด แล้วเขียน — จบได้เอง |

> ติดปัญหาให้พิมพ์ในแชทห้องได้เลย เราหยุดรอทุกขั้น

### ขั้นที่ 1–4 · ติดตั้งและตั้งค่า

รันใน Terminal ทีละคำสั่ง

```bash
mkdir -p my-work/day1-workshop
cd my-work/day1-workshop

hermes setup     # ตั้งค่าผ่านตัวช่วย
hermes model     # เลือก provider / model
hermes           # เปิด CLI
```

ถ้าติดตั้งไม่ผ่าน ให้ดู [Quickstart ทางการ](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart/)
หรือ [Windows WSL2 Guide](https://hermes-agent.nousresearch.com/docs/user-guide/windows-wsl-quickstart) แล้วแจ้งในแชทห้อง

### ขั้นที่ 5 · ทดลองสั่ง Agent ทำงาน

วางใน Hermes chat

```text
ดูว่าตอนนี้เราอยู่โฟลเดอร์ไหน และในโฟลเดอร์นี้มีไฟล์อะไรบ้าง
บอกด้วยว่าคุณใช้เครื่องมืออะไรถึงรู้คำตอบ
```

**ต้องเห็น** · ชื่อโฟลเดอร์ที่ตรงกับของจริง และชื่อเครื่องมือที่มันเรียก
ถ้ามันตอบโดยไม่เรียกเครื่องมือเลย แปลว่ามันกำลังเดา — ให้สั่งใหม่ว่า “ไปดูของจริงก่อน”

### ขั้นที่ 6 · ให้ Agent อ่านและสร้างไฟล์

```text
สร้างไฟล์ notes.md ในโฟลเดอร์นี้ เขียนว่าวันนี้เราเรียนอะไร 3 บรรทัด
แล้วเปิดไฟล์นั้นอ่านกลับมาให้ผมดู
```

**ต้องเห็น** · ไฟล์ `notes.md` อยู่จริงในโฟลเดอร์ (เปิดด้วยตาเราเอง ไม่ใช่เชื่อคำบอกเล่า)

### ขั้นที่ 7 · Task ที่มีหลายขั้นตอน

```text
ทำงานอยู่ในโฟลเดอร์นี้เท่านั้น

1. สร้างไฟล์ data.md แล้วใส่รายการงานสมมติ 5 รายการ พร้อมสถานะ
2. อ่านไฟล์นั้นกลับมา แล้วนับว่ามีงานที่ยังไม่เสร็จกี่รายการ
3. เขียนผลสรุปลงไฟล์ summary.md
4. ปิดท้ายด้วยการ list โฟลเดอร์ ยืนยันว่าทั้งสองไฟล์มีอยู่จริง

ทุกขั้นให้บอกว่าใช้เครื่องมืออะไร และได้อะไรกลับมา
```

**ต้องเห็น** · ไฟล์สองไฟล์ในโฟลเดอร์ และลำดับการเรียกเครื่องมือที่เราตามย้อนได้
นี่คือ Agent Loop ที่เห็นด้วยตาจริง ๆ ไม่ใช่แค่ภาพบนสไลด์

## Workshop 2 · Personal AI Assistant
**21:45 – 22:00 น. · 15 นาที**

นี่คือจุดเริ่มต้นของ Workshop Project ที่จะพัฒนาต่อทั้งห้าคืน — **ใช้งานจริงของตัวเอง ไม่ใช้โจทย์สมมติ**

### สี่อย่างที่ต้องกำหนดให้ Assistant

| | คำถามที่ต้องตอบ |
|---|---|
| บทบาท | Assistant นี้ทำหน้าที่แทนเราในเรื่องอะไร |
| รูปแบบการทำงาน | น้ำเสียง ความละเอียด และรูปแบบผลลัพธ์ที่ต้องการ |
| งานที่ต้องช่วย | งานประจำสองถึงสามอย่างที่ทำซ้ำทุกสัปดาห์ |
| โจทย์จริงของคุณ | ทดลองกับงานจริงทันที |

### Prompt ตั้งต้น — คัดลอกไปใช้ได้เลย

```text
ทำงานอยู่ในโฟลเดอร์ day1-workshop เท่านั้น

คุณคือผู้ช่วยส่วนตัวของผม
- บทบาท: [ช่วยผมเรื่อง ________]
- รูปแบบ: ตอบเป็นภาษาไทย สั้น เป็นข้อ ๆ ไม่ต้องเกริ่น
- งานประจำที่ผมทำซ้ำ: [1. ________  2. ________  3. ________]

กติกา
1. ถ้าข้อมูลไม่พอ ให้ถามกลับ อย่าเดา
2. ผลงานให้เขียนลงไฟล์ในโฟลเดอร์นี้ ไม่ใช่ตอบยาว ๆ ในแชท
3. ก่อนลบหรือเขียนทับไฟล์เดิม ให้ถามผมก่อนเสมอ

งานแรก: [เขียนงานจริงของคุณ 1–2 บรรทัด]
```
