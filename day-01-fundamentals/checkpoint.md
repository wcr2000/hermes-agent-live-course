ติ๊กให้ครบทั้งหกข้อก่อนปิดเครื่อง

- [ ] พิมพ์ `hermes` แล้วเปิด CLI ได้ และเลือก Model Provider ได้เรียบร้อย
- [ ] Agent ตอบงานแรกได้ และเราเห็นว่ามันเรียกเครื่องมืออะไรบ้าง
- [ ] มีไฟล์ที่ Agent สร้างขึ้นจริงในโฟลเดอร์ และเราเปิดอ่านด้วยตาเองแล้ว
- [ ] รัน Task หลายขั้นตอนจบได้ โดยเราไม่ต้องสั่งทีละขั้น
- [ ] แยกได้ว่า LLM, Chatbot และ Agent ต่างกันตรงไหน (อธิบายให้เพื่อนฟังได้)
- [ ] มี Personal AI Assistant ที่กำหนดบทบาทและงานประจำไว้แล้ว

## ข้อที่คนพลาดมากที่สุดคือข้อ 3
Agent เขียนได้เนียนพอที่จะทำให้เราเชื่อว่ามันทำแล้ว — เปิดโฟลเดอร์ดูเองใช้เวลา 10 วินาที และเปลี่ยนทุกอย่าง

## ถ้าทำไม่ทัน
ติดตั้งไม่ผ่านให้ดู [Troubleshooting](../resources/troubleshooting.md) แล้วแจ้งในแชทห้อง
ยังไม่ต้องติ๊กข้อที่ยังไม่ได้ลองจริง — คืนที่ 2 เราจะเริ่มจากจุดที่แต่ละคนอยู่

## การบ้าน
ใช้ Agent กับงานจริงหนึ่งงาน แล้วจดไว้ว่าติดอะไร (สามบรรทัดพอ)
