## Session 1 · จาก LLM สู่ AI Agent (20:00 – 20:25)

### LLM vs Chatbot vs Agent

| | LLM | Chatbot | Agent |
|---|---|---|---|
| หน้าที่หลัก | ทำนายข้อความถัดไป | โต้ตอบเป็นบทสนทนา | รับเป้าหมายแล้วทำให้สำเร็จ |
| ความจำ | ไม่มี | เท่าที่อยู่ใน Context | Session + Persistent Memory |
| เครื่องมือ | ไม่มี | จำกัด | ไฟล์ · Terminal · Search · API |
| ผลลัพธ์ | ข้อความ | คำตอบ | งานที่เสร็จแล้วจริง |

### Agent Loop

```
Understand → Plan → Act → Observe → Verify
                ↑                        │
                └──── ยังไม่ถึงเป้าหมาย ─┘
```

| ขั้น | ทำอะไร |
|---|---|
| Understand | ตีความเป้าหมายของผู้ใช้ |
| Plan | แตกงานเป็นขั้นตอนย่อย |
| Act | เรียกใช้ Tool ที่เหมาะกับงาน |
| Observe | อ่านผลลัพธ์ที่เกิดขึ้นจริง |
| Verify | ตรวจว่าถึงเป้าหมายแล้วหรือยัง |

### องค์ประกอบห้าอย่างของ Agent

| องค์ประกอบ | คืออะไร | ลงรายละเอียดคืนไหน |
|---|---|---|
| Model | สมองที่ใช้คิดและตัดสินใจ | คืนที่ 1 |
| Context | ข้อมูลที่อยู่ตรงหน้าในรอบนี้ | คืนที่ 2 |
| Memory | สิ่งที่ยังจำได้เมื่อกลับมาใหม่ | คืนที่ 2 |
| Tools | มือที่ใช้ลงมือทำงานจริง | คืนที่ 3 |
| Environment | พื้นที่ทำงาน ไฟล์ และระบบรอบตัว | คืนที่ 3 |

## Session 2 · ทำความรู้จัก Hermes Agent (20:25 – 20:50)

Hermes Agent คือ Agent Framework แบบ Open Source ที่ทำงานอยู่บนเครื่องของเรา
สั่งงานผ่าน Terminal และมองเห็นไฟล์จริงในพื้นที่ทำงานที่เรากำหนดให้

- ทำงานกับไฟล์และคำสั่งบนเครื่องได้จริง
- เลือก Model Provider ได้ตามที่เราตั้งค่า
- ต่อยอดด้วย Memory, Skills และ MCP ได้

### สถาปัตยกรรม

| ส่วนประกอบ | หน้าที่ |
|---|---|
| Workspace | ขอบเขตไฟล์และโปรเจกต์ที่ Agent มองเห็น |
| Model Provider | Model ที่ใช้คิด พร้อม Configuration |
| Terminal & Files | ช่องทางที่ Agent ใช้ลงมือทำงาน |
| Execution Loop | ตัวคุมจังหวะ คิด · ทำ · ตรวจ |

```
Prompt → Context → Model → Tool Call → Observe → Result
```
