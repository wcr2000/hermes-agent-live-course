## ลำดับเรียนที่เสนอ (120 นาที)
| เวลา | กิจกรรม |
|---|---|
| 0–15 นาที | ทบทวนและอธิบายแนวคิดด้วยภาพ |
| 15–35 นาที | ผู้สอนสาธิตงานปลายทาง |
| 35–75 นาที | ผู้เรียนทำ Workshop ตามขั้นตอน |
| 75–85 นาที | พัก |
| 85–110 นาที | ทดลองกรณีผิดพลาดและปรับงาน |
| 110–120 นาที | ตรวจ checkpoint และถามตอบ |
